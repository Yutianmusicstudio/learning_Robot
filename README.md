# 钢琴机器人 · 从零开始学习路线

> 起点：会一点编程，有一套 Arduino 套件 + 一块 STM32 主板，零机械/电子基础。
> 目标：做一台能自己弹钢琴的机器人。

---

## 一、先把"钢琴机器人"拆成三个难度档

很多人一上来想的是"仿人双手弹钢琴"，那是研究所级别的项目（Google/丰田都做过，团队+数年）。实际上这件事有三个台阶，**必须从第一台阶开始**：

| 档次 | 形态 | 技术核心 | 你需要的时间 | 成本 |
|---|---|---|---|---|
| **L1 自动演奏装置** | 一排电磁铁压在琴键上方，按 MIDI 谱敲击 | 电子驱动 + 时序控制 | 1~3 个月 | 300~800 元 |
| **L2 机械手指 / 单臂** | 几根会动的"手指" + 一条横移轴，能移动到不同音区 | 运动学 + 轨迹规划 + 机械设计 | 6~12 个月 | 2000~6000 元 |
| **L3 仿人双臂** | 两只多自由度手，视觉读谱，力控触键、控制力度和踏板 | 力控 + 视觉 + 学习算法 | 数年 | 数万起 |

**这个仓库的路线是 L1 → L2**，L3 只给方向。

L1 不是"简化版"，它是真正能出效果的东西：世界上大部分"机器人弹钢琴"的视频其实都是 L1。先把 L1 做出来，你会自然学到 L2 需要的一切。

---

> **动手之前先读这个**：[`docs/field-landscape.md`](docs/field-landscape.md) —— 雅马哈 Disklavier 已经把"自动演奏"做完了 40 年，这个方向现在真正没解决的是什么、什么才算有意义的工作。**先想清楚为什么做，再决定做什么。**

## 二、总路线图（建议 6 个阶段）

```
Phase 0  安全与基本功        2 周   —— 一个电磁铁，敲响一个琴键
Phase 1  八键自动演奏        4 周   —— 电脑读 MIDI → Arduino → 弹《小星星》
Phase 2  机械结构 + 扩展     6 周   —— 3D 打印支架，扩到 2 个八度，加力度控制
Phase 3  迁移到 STM32        4 周   —— 精确时序、USB-MIDI 设备、更多通道
Phase 4  会动的手指          8 周+  —— 舵机/步进 + 运动学 + 仿真登场
Phase 5  感知与智能          长期   —— 摄像头读谱、力反馈、强化学习
```

各阶段详细任务见 [`docs/roadmap.md`](docs/roadmap.md)。

## 三、你问的四个问题，直接回答

### 1. 需要点亮哪些前置条件？

按"用得上的顺序"排，不要按教科书顺序学。完整清单在 [`docs/prerequisites.md`](docs/prerequisites.md)，核心是这 6 块：

1. **电子安全常识**（最紧急，1 周）——欧姆定律、MCU 引脚只能出 20mA、感性负载必须加续流二极管、共地。**不学这个第一周就会烧板子。**
2. **嵌入式 C**（贯穿全程）——GPIO / PWM / 定时器 / 中断 / 串口。
3. **MIDI 协议**（1 天）——钢琴机器人的"乐谱数据格式"，整个项目的输入。
4. **Python 上位机**（1 周）——解析 MIDI、发指令、调参数。
5. **机械基础**（Phase 2 再学）——力矩、连杆、行程、公差。
6. **控制理论入门**（Phase 4 再学）——开环 vs 闭环、PID、正/逆运动学。

> 不需要先学：ROS、深度学习、SLAM、控制理论的严格数学推导。这些在 L1/L2 阶段一行都用不上，先学只会消耗热情。

### 2. 需要哪些硬件？

详细选型 + 型号 + 避坑在 [`docs/hardware.md`](docs/hardware.md)（**在美国的话看文末的美元采购附录**）。Phase 0/1 的最小清单（约 400 元）：

- 一台**二手 61 键电子琴**（**不要一上来碰真钢琴**，真钢琴按键需要的力是电子琴的 3~5 倍）
- 8 个 **12V 推拉电磁铁**（如 JF-0530B 一类，推力 5N、行程 5mm）
- 8 个 **逻辑电平 MOSFET**（IRLZ44N，**不能用 IRF540N**）或一块现成的 8 路 MOSFET 驱动模块
- 8 个 **续流二极管**（1N4007 或肖特基 1N5819）——漏掉这个 = 烧 MCU
- **12V / 10A 开关电源** + 1000µF 电解电容
- 面包板、杜邦线、你已有的 Arduino
- （可选但强烈建议）**万用表**

### 3. 要学 3D 打印吗？

**要，但不是现在，是 Phase 2。** 详见 [`docs/3d-printing.md`](docs/3d-printing.md)。

- **它解决的问题**：把电磁铁精确、可重复地固定在每个琴键正上方。这个"支架"手工做几乎不可能做准，3D 打印是最省事的方案。
- **真正要学的是 CAD，不是打印机**。推荐 **Fusion 360**（个人版免费、参数化建模、机械设计事实标准）或 **Onshape**（网页版免费）。打印机只是输出设备。
- **不买打印机也能做**：淘宝/嘉立创的打印服务几块钱一件；或者先用 2020 铝型材 + 亚克力激光切割件搭框架。**建议 Phase 1 先用铝型材/木板搭出能用的原型，Phase 2 再上 3D 打印。**

### 4. 机器人公司用的仿真软件，我要用吗？

**你的观察是对的，但对 L1 阶段仿真基本没用，从 L2（Phase 4）开始才值得投入。** 详见 [`docs/simulation.md`](docs/simulation.md)。

仿真真正解决的问题是：**机构还没造出来之前，验证它够不够得着、会不会撞、轨迹是否平滑、需要多大力矩**。电磁铁直上直下敲一个键，这些问题都不存在，仿真等于在画一个你已经知道答案的图。

到 Phase 4 有多关节手指时，按这个顺序：

| 软件 | 定位 | 什么时候用 |
|---|---|---|
| **PyBullet** | 最轻，`pip install` 就能跑 | 入门第一站，两周内理解正逆运动学、碰撞、PID |
| **MuJoCo** | 接触力学最强，已开源免费 | 模拟"手指压下琴键"的接触力，本项目最对口 |
| **Gazebo + ROS 2** | 工业/学术标准 | 想走机器人行业路线时再学，学习曲线陡 |
| **Isaac Sim / Isaac Lab** | 强化学习 + 高保真渲染 | Phase 5，需要 NVIDIA 显卡 |
| **Fusion 360 自带运动仿真** | 机构干涉/行程检查 | 画完结构件顺手就能验证，性价比最高 |

一句话：**Phase 4 之前，你的"仿真器"就是真实的电子琴本身**——它比任何软件都准，而且免费。

## 四、最重要的三条忠告

1. **每个阶段都必须产出一个"能响的东西"。** 弹出走调的《小星星》比看完十套教程有用得多。
2. **先电子琴，后真钢琴。** 真钢琴的击弦机需要的是"动能"不是"静压力"，力学模型完全不同，且弄坏了很贵。
3. **电磁铁会烫。** 长时间通电的电磁铁能到 80°C 以上，会烧线圈、烫化 3D 打印件。必须用 **peak-and-hold（先满功率击打 ~25ms，再降到 ~35% 占空比保持）**——这是本项目最关键的一个技巧，Phase 0 的代码里就实现了。
