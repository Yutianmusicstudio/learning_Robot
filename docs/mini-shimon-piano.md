# 钢琴版 mini Shimon

> **目标定下来了**：做一台钢琴版的 mini Shimon——不是自动演奏钢琴，是一个会弹钢琴的**乐手**。
> 本文取代 [`project-proposal.md`](project-proposal.md) 的目标定义；那份的可行性论证和
> 研究向的成果预估继续有效，但不再是主线。

---

## 一、和钟琴版的关键差异：延音

这是架构级的，不是细节。

| | 钟琴 / 马林巴（mini Shimon） | 钢琴 |
|---|---|---|
| 击发之后 | **槌立刻自由**，音条自行衰减 | **手指必须按住**，一松就被制音器闷掉 |
| 一根执行器同时能做的事 | 敲完就走，去下一个音 | **按住一个音时，它被锁死** |
| 4 根臂能干什么 | 连续跑遍全键盘 | **一个四音和弦就把四根臂全占死** |

**结论：纯移动臂方案在钢琴上不成立。** 必须换架构。

## 二、v1 架构：混合式

```
┌─ 固定电磁铁阵列（8 → 16 路）   和声 · 持续音 · 低音
│                                便宜；可同时按下多个
├─ 可移动臂 ×1（后续可加到 2）   旋律 · 力度表现
│                                BLDC + 同步带 + 力控
├─ 延音踏板电磁铁 ×1             ★ 解放固定阵列的持续负担
│                                在钟琴上无意义；在钢琴上是前提
└─ 表情头（舵机 ×2）             点头 + 转向：预告节拍与注意力
                                 ★ 这是"乐手"与"自动钢琴"的分界线
```

### 为什么踏板这么关键
一个 $10–15 的大电磁铁踩下延音踏板 → 所有制音器抬起 → **所有手指立刻解放**。
它买到的音乐自由度比多加两根臂还大。**在 v1 里就要有，不要排到最后。**

### 为什么头不能砍
Shimon 的头是它的**论点本身**——用动作预告节拍、和声与注意力。
没有头，你造的是 Disklavier；有头，你造的是一个乐手。
成本：两个舵机 + 打印件，约 $25。

### 最有意思的软件问题：指法分配
哪根臂弹哪个音、何时开始移动、来不来得及、什么时候踩踏板。
钟琴版已经有这个调度问题，**钢琴的延音约束让它难一个量级**。这是这台机器的智力核心。

## 三、不要照抄实验室的部分

| 他们用的 | 单价 | 你用什么 | 单价 |
|---|---|---|---|
| **maxon EPOS4 Micro 24/5 EtherCAT** | $500–900 | 云台 BLDC + SimpleFOC / B-G431B-ESC1 | ~$60 |
| **EtherCAT** 工业现场总线 | — | 一块 STM32 直接控制，或 UART/CAN | $0 |
| Copley Xenus（大 Shimon） | $500–1500 | 同上 | — |

**原理完全一样**（电流环 / 速度环 / 位置环），差的是可靠性、容错和价格。

## 四、块状清单（业余时间用）

按"一次能做完的块"排，不按周排。**有空就拿一块下来做完，每块结束时都要有个能动的东西。**

### A · 起步（不用买任何东西）
- [ ] **A1** 第一课：LED + peak-and-hold 状态机 　`一个晚上`
- [ ] **A2** ★ 下单阶段 A 全部物料（电磁铁 2–3 周才到） 　`30 分钟`
- [ ] **A3** 去 The Hive / FIS 办设备培训（有排队前置期） 　`一次`

### B · 单路打通
- [ ] **B1** 面包板搭 1 路 MOSFET 驱动，第一次上 12V 　`一个晚上`
- [ ] **B2** 敲响第一个琴键 　`一个晚上`
- [ ] **B3** peak-and-hold 调参 + 连续 5 分钟温度测试 　`一个晚上`

### C · 迁到 STM32
- [ ] **C1** PlatformIO + STM32duino 环境，点亮一个灯 　`一个晚上`
- [ ] **C2** peak-and-hold 移植到 STM32 　`一个晚上`
- [ ] **C3** 串口协议 + Python 发 MIDI 　`一个晚上`

### D · 8 路 + 第一首曲子
- [ ] **D1** 面包板扩到 8 路 　`一个周末`
- [ ] **D2** 弹出第一首完整曲子 　`一个晚上`
- [ ] **D3** ★ **加延音踏板电磁铁**——立刻能听出音乐性的变化 　`一个晚上`

### E · 第一块 PCB
- [ ] **E1** KiCad 入门 + 画 8 路驱动板原理图 　`一个周末`
- [ ] **E2** 画 PCB 布局，压在 100×100mm 内 　`一个周末`
- [ ] **E3** The Hive 铣一块 v1，当天焊上验证 　`一个周末`
- [ ] **E4** 改版后发 JLCPCB 打 5 片 　`30 分钟 + 等一周`
- [ ] **E5** 焊完 + 全通道验证 　`一个周末`

### F · 变成一个乐手
- [ ] **F1** 扩到 16 路（2 块板级联）+ 机架 + 打印夹具 　`两个周末`
- [ ] **F2** ★ **做头**：两个舵机 + 打印外壳，会点头 　`一个周末`
- [ ] **F3** 头跟着拍子动——**第一次它看起来像个乐手** 　`一个晚上`
- [ ] **F4** USB-MIDI Class：电脑免驱识别成一台乐器 　`一个周末`

### G · 移动臂
- [ ] **G1** BLDC + SimpleFOC + 编码器，单关节转起来 　`两个周末`
- [ ] **G2** 力控：能模拟虚拟弹簧 / 阻尼 　`一个周末`
- [ ] **G3** 同步带 + 导轨横移轴 + 限位回零 　`两个周末`
- [ ] **G4** 移动臂弹出旋律，固定阵列伴奏 　`若干周末`

### H · 指法分配
- [ ] **H1** 写调度器：哪根臂弹哪个音、何时移动、何时踩踏板
- [ ] **H2** 处理"来不及"的情况——降级策略

**F3 是第一个能让人"哇"一声的时刻，而它排在移动臂之前。** 这不是巧合：
业余项目需要早一点拿到成就感，才活得下去。

## 五、业余节奏的四条纪律

1. **每块结束时留一个能动的东西**，绝不留半截
2. **不要安排需要连续三周才能完成的任务**
3. **提前、成批下单**——业余节奏下 2–3 周的到货期更致命
