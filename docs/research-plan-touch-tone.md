# 研究计划：可编程触键力学平台

> 一台能精确、可重复地控制"手指如何压下琴键"的机器，用来回答钢琴教学里
> 争论了两百年、却缺少可复现数据的问题。
>
> 这是 [`roadmap.md`](roadmap.md) Phase 2 之后分出的研究支线，不是替代它。

---

## 一、为什么这件事必须用机器人做

人做不到两件事，而这两件事恰好是这个问题的全部要害：

1. **重复精度**。要判断"触键方式是否改变音色"，必须先让两次触键的**击弦速度完全相同**——否则你测到的只是"响度不同"。人类钢琴家的击弦速度重复性大约在 ±5~10%，而你需要 **±1%**。
2. **变量解耦**。教学语言里的"放松""重量""贴键"是一堆纠缠在一起的物理量（手指质量、刚度、阻尼、初速度、力的上升率）。人没法只改其中一个而保持其余不变。机器可以。

**这台机器的价值不是"会弹琴"，是"能做对照实验"。**

## 二、文献已经做完了什么（先读，别重造轮子）

三条结论直接约束了本计划的设计：

### 结论 1：单音的"音色"，物理上几乎只由击弦速度决定
钢磬的击弦机有**擒纵（escapement/let-off）**：撞弦前不到 1 ms，顶杆就脱离了槌轮，**琴槌是自由飞行着撞上琴弦的**（Askenfelt & Jansson，KTH，光学位移测量）。手指在那一刻已经和琴槌断开了因果链。
→ 所以"手指姿势直接塑造琴弦振动"这个说法，在单音层面基本站不住。

### 结论 2：但听众确实能分辨——差别在**噪声**，不在琴弦
Goebl、Bresin & Galembo 用 C4 对比"按下(pressed，手指先贴键)"与"击下(struck，手指从空中带速度落下)"：
- **把起音前的手指—琴键接触噪声剪掉之后，听众的辨别率掉到随机水平。**
- 噪声保留时，也**只有一半听众**能稳定分辨，另一半是随机。

→ 两个重要启示：(a) 可听的差异来自**非琴弦成分**（指—键接触噪声、键底触底声）；(b) **听众存在明显的双峰分化，组平均会把真实结构抹掉**——后面的听音实验必须按个体报告。

### 结论 3：所谓"旋律提前"，主要是响度的副产品
演奏中旋律声部通常比其他声部**早约 30 ms** 到达。Goebl（JASA 2001，22 位钢琴家，Bösendorfer 电脑监测三角琴）发现：**在手指—琴键层面，这个提前量几乎归零**——是因为旋律音键速更快，琴槌先到，并非钢琴家有意提前。

→ **这条结论留下了一个人做不了、机器能做的问题**（见下文轨道 C）。

### 还有一条被忽略的线索
Askenfelt 指出：**琴槌杆是柔性的**，staccato 触键时较重的槌头会在柔性杆上上下振动，而这个弯曲运动**会部分沿击弦机传回琴键，钢琴家很可能能"摸"到它**。
→ 提示"触键与音色"可能有相当一部分是**触觉现象而非听觉现象**：演奏者感觉到了差别，然后归因给了声音。这是个可证伪的假说（轨道 D）。

## 三、三条实验轨道

### 轨道 A（必做，平台验收）：复现"按 vs 击"
**不是为了创新，是为了证明你的平台是对的。** 因为你已经知道正确答案（结论 2），所以它是一把标尺：如果你的机器复现不出 Goebl 的结果，说明测量链有问题，此时任何新发现都不可信。

- 条件：pressed / struck，**击弦速度用闭环迭代对齐到 ±1%**
- 测量：全频段录音 / 剪除起音噪声后的录音 / 琴槌速度 / 指力曲线 / 琴键位移
- 判据：剪掉噪声后 ABX 辨别率不显著高于 50%；保留噪声时出现听众双峰分化

### 轨道 B（物理贡献）：手指机械阻抗扫描
教学语言里的"松弛的手臂重量" vs "僵硬的手指"，物理上就是末端执行器的**质量、刚度、阻尼**三个参数。力控执行器可以**任意模拟这三个参数**（阻抗控制），而人不能只改其中一个。

- 自变量：等效质量 m、刚度 k、阻尼 c（各 3~4 档，正交设计）+ 指尖材料（硬质 POM / 硅胶 / 仿肉垫）
- 控制量：击弦速度恒定
- 因变量：琴槌杆弯曲（用第二组光电门测槌头相对槌杆根部的相位差）、起音噪声能量、频谱质心、以及 ABX 可辨性
- 这一块是真空白：**没人系统扫过它**，而它直接把教学术语翻译成了物理量

### 轨道 C（推荐作为主实验）：旋律提前量是有用还是无用
Goebl 证明了 30 ms 提前是响度的**副产品**。但没人回答：**这个副产品在感知上到底有没有帮助？**
在真人演奏上无法回答——因为响度和时间差在人手上是锁死的。**双执行器机器可以把它们完全解耦**，甚至造出"更响却更晚"这种人类做不出来的刺激。

- 自变量：Δ响度（旋律音比伴奏高 0 / 3 / 6 / 9 dB）× Δ时间（旋律 −30 / −15 / 0 / +15 / +30 ms，含**负提前**）
- 因变量：听众"旋律有多突出"的评分 / 强制选择的辨别阈（JND）
- 被试分层：**职业钢琴家 / 业余学习者 / 非音乐训练者**（呼应结论 2 的双峰分化）
- 产出是一个**教师能直接用的数字**："要让听众听出旋律，实际需要多少 dB？提前多少毫秒才起作用？"

**推荐顺序：A → C → B**，D 作为远期。
C 排在 B 前面，因为它出结果最快、教学价值最直接，而且它需要搭建的听音测试基础设施，B 后面照样要用。

### 轨道 D（远期，最有意思）：触觉解耦
假说：钢琴家感知到的"音色差别"，部分来自**手指感受到的击弦机反馈**，而非耳朵。
做法：让钢琴家在力反馈琴键上演奏，独立操纵"听到的声音"与"摸到的反馈"，看他们的音色判断跟着哪一个走。这需要一台双向力反馈琴键，工程量大，放在最后。

## 四、硬件设计

### 4.1 执行器：不要用电磁铁

电磁铁本质是开关，力—位移曲线强非线性，无法编程出任意力—时间曲线。本平台需要的是**可编程力控**。

| 方案 | 评价 |
|---|---|
| **无刷云台电机 + FOC 电流环 + 短力臂**（GB2208/5208 + SimpleFOC 或 B-G431B-ESC1） | ✅ **推荐**。直驱、可反驱、力矩=电流、成本低（约 ¥350/轴）。30mm 力臂下可得数牛顿，足够 |
| 线性音圈作动器（VCA） | ✅ 最理想（力—电流完全线性、无齿槽），但成品 ¥800~3000。可用大口径低音喇叭去掉纸盆改造 |
| 舵机 / 步进 | ❌ 位置控制、不可反驱、力控极差 |
| 电磁铁 | ❌ 只能做轨道 A 的粗略版本 |

> 阻抗控制（模拟任意质量/刚度/阻尼）需要电机端的位置环跑到 kHz。
> **编码器必须用 SPI 的 MT6701 / AS5047P，不要用 I2C 的 AS5600**——AS5600 的速率和内部滤波延迟撑不住阻抗控制环。

### 4.2 测量链（整个平台的成败在这里）

| 量 | 方案 | 关键要求 / 陷阱 |
|---|---|---|
| **击弦速度**（最重要） | 两只槽型光电开关，让**琴槌杆**先后遮断两束光，STM32 输入捕获计时 | 这是整个实验的控制变量。forte 时槌速约 4~5 m/s，pp 时约 0.5 m/s；要 1% 精度需 µs 级计时，STM32 轻松达到。**尽量不要在槌上加配重**，若必须加旗标须 <0.1 g 且全程固定 |
| **指尖力** | 应变梁传感器 + INA333 + **ADS131M04**（24bit, 可到 32 kSPS）；另加压电片捕捉瞬态 | ⚠️ **绝对不要用 HX711**——它只有 10~80 SPS，而起音瞬态只有十几毫秒，等于什么也没测到。这是这类项目最常见的致命错误 |
| **琴键位移** | 键下反射式光电（QRE1113），用千分表标定成位移曲线 | 必须测**琴键**而非执行器位置——"击下"触键时两者是分离的 |
| **琴槌杆弯曲**（轨道 B） | 第二组光电门测槌头 vs 槌根的到达时差 | 可选，但这是轨道 B 的核心观测量 |
| **声音** | 测量话筒（UMIK-1 带校准文件 / ECM8000）+ 96 kHz·24 bit 声卡 | **固定位置、固定增益、关掉一切 AGC 与压缩**，位置和角度写进记录 |
| **结构声** | 音板上贴 ADXL1002 高量程加速度计 | 用来把结构传声与空气传声分开 |
| **环境** | 温湿度记录仪 | 钢琴会随温湿度跑音，这是多天实验的真实混淆项 |

### 4.3 机架
反作用力必须由机架吃掉，不能吃掉冲击。要求：**机架在峰值力下的变形 ≪ 琴键行程**。
用铝型材 + 钢/花岗岩配重底座，装好后用千分表实测机架在 20 N 下的挠度并写进论文。机架与钢琴之间做减振隔离，避免机架自身共振混进录音。

## 五、实验方法学（这一节决定结论能不能信）

### 5.1 必须先做功率分析
先用轨道 A 的重复性数据测出平台本底噪声，再回答"每个条件要打多少次"。
**如果平台的重复性噪声大于你想检出的效应，实验不该开始。**

### 5.2 混淆因素清单（逐条要有对策）

| 混淆项 | 为什么致命 | 对策 |
|---|---|---|
| **槌毡压实** | 同一个音反复敲几千次，毡会压实变硬，音色**在实验过程中单向漂移** | 条件顺序**完全随机化，绝不分块**；每 N 次插入一个参考条件做基线跟踪；记录累计击打次数；分散到多个音上 |
| 跑音 / 整调漂移 | 频谱特征直接受影响 | 记录温湿度；实验前请技师整调并在中期复检；选对小幅音高漂移稳健的特征 |
| 机架柔度 | 冲量被机架吃掉 | 实测挠度并报告 |
| 房间声学 | 反射改变频谱 | 固定近场话筒位置（约 30 cm）、固定时段 |
| 实验者偏倚 | 这个题目情绪化，太容易"找到想要的结果" | **预注册**假设与分析方法；ABX 双盲；分析管线在揭盲前写完并冻结 |
| 多重比较 | 频谱特征一多，总能"显著" | 事先指定主要因变量；其余作探索性并做校正 |
| 听众异质性 | 结论 2 已证实存在双峰分化 | **必须报告个体层面结果**，不能只报组均值；被试按训练程度分层 |

### 5.3 数字钢琴 = 免费的假阳性对照组（强烈建议加进设计）

数字钢琴的琴键传感器通常只有两三个接触点，靠**琴键经过两点的时间差**换算出一个
velocity 数值。除此之外，触键的一切信息——力的曲线形状、手指等效质量、是否贴键起手
——**在那一刻就被压缩成一个标量丢掉了**。

所以在数字钢琴上，**同一个 velocity 必然回放出完全相同的采样**。
"触键改变音色"在那里是物理上不可能的（机械噪声除外）。

这给了你一个几乎免费的方法学工具：

> **把整套实验流程原封不动地在数字钢琴上跑一遍。**
> 如果你的分析管线在那里"检出了差异"，说明管线有假阳性——
> 在你把它用到声学钢琴上之前，必须先修好。

这条对照在 S0 阶段就能做，成本为零，却能挡掉这类研究最常见的一种失败。

### 5.4 统计
混合效应模型（音高、场次作随机效应）；ABX 用二项检验并**逐被试**报告；效应量与置信区间优先于 p 值。

## 六、分阶段计划

| 阶段 | 周 | 内容 | 验收标准（量化） |
|---|---|---|---|
| **S0 验证测量链** | 1~6 | 在**数字钢琴**上用现有 Phase 1 硬件跑通采集。数字琴的 MIDI velocity 就是击弦速度的现成真值 | 同一指令重复 200 次，MIDI velocity 标准差 ≤ 1 |
| **S1 力控单指** | 7~16 | BLDC + FOC 电流环 + 力传感 + 阻抗控制 | 能按指定力—时间曲线执行，力跟踪误差 < 5%；能稳定模拟三组不同 (m,k,c) |
| **S2 上声学钢琴** | 17~24 | 光学测槌速、录音链、机架、环境记录 | 击弦速度测量重复性 ≤ 1%；机架 20 N 下挠度 < 0.05 mm |
| **S3 轨道 A（验收）** | 25~30 | 复现 pressed vs struck | 复现出"剪掉噪声后辨别率回到随机"这一已知结论 |
| **S4 轨道 C（主实验）** | 31~42 | 双执行器，Δ响度 × Δ时间正交，三层被试听音测试 | 得到旋律突出度的 JND 曲面 |
| **S5 产出** | 43~52 | 数据集整理、开源硬件、论文 | 数据集可下载复现；投出去 |

**S0 现在就能开始，用的全是你已有的东西。**

## 八、产出与去向

三样东西，对应"意义的三个来源"：

1. **开源硬件**：CAD + BOM + 固件，让别人能重建这台机器
2. **开放数据集**：对齐的（指令 / 指力曲线 / 琴键位移 / 击弦速度 / 音频 / 环境）元组。**这是最有长期价值的一项**——文献里明确抱怨过"现有钢琴数据集要么有指法没动作，要么有动作但指法不可靠"
3. **一篇论文 + 预注册**

投稿去向（按友好程度）：**NIME**（新音乐表达界面，最欢迎这类软硬件工作）→ **ISMA**（国际音乐声学研讨会，Goebl 那篇"Once again"就发在这里）→ **DAFx** → **JASA**（若数据够硬）→ **Frontiers in Psychology / Performance Science**（偏感知与教学）。

## 九、风险与失败模式

| 风险 | 概率 | 应对 |
|---|---|---|
| **主结果是零结果**（触键在等击弦速度下不改变琴弦音色） | **高，而且这很可能就是事实** | **提前接受它**。预注册之后，零结果同样可发表，而且对钢琴教学价值很大——这个领域充斥着无法证伪的说法。真正的新意在轨道 B 和 C，那里出正结果的可能性高得多 |
| 力传感器带宽不足 | 中 | 别用 HX711；提前用敲击测试验证带宽 |
| 槌毡漂移吃掉效应 | 中高 | 随机化 + 插入参考条件 + 多音分散 |
| 力控环调不稳 | 中 | S1 设了 10 周，先在数字琴上调 |
| 招不到足够听音被试 | 低（你有工作室） | 这恰好是你相对于工程实验室的优势 |
| 范围膨胀 | **高** | 四条轨道**只做 A + C**。B 和 D 写进"未来工作" |

## 十、为什么是你

这个领域自己写在论文局限性里的话是：**"客观指标能量化统计相似度，却抓不住真正有音乐性的整体质感。"**
翻译过来就是：**这个领域缺的不是工程师，是能提出正确音乐问题、并且找得到职业钢琴家做被试的人。**

机器人实验室造得出比你好十倍的机械手，但他们问不出"旋律要提前多少毫秒才听得出来"，也约不到 30 位钢琴家来做 ABX。
