## 第 1 组 · 电子安全常识（Phase 0 前必须完成，约 3 小时 + 动手）

这一组是唯一"不学就会出事"的。烧掉 MCU、烧掉电源、烫伤，都发生在这里。

### 必须理解的 8 件事

1. **欧姆定律 U = I × R，功率 P = U × I。** 会算：12V 电磁铁线圈 24Ω → 电流 0.5A → 功率 6W（这 6W 全变成热）。
2. **MCU 引脚是"信号"不是"电源"。** Arduino 单引脚最大约 20mA，全芯片约 200mA。电磁铁要 500mA+，**直接接引脚必烧**。引脚的作用是去"开关"一个 MOSFET。
3. **MOSFET 当开关**：栅极(G)给高电平 → 漏极(D)和源极(S)导通。必须选 **逻辑电平（logic-level）MOSFET**，比如 IRLZ44N；**IRF540N 需要 10V 栅压，用 5V 驱动它会半导通、发烫、烧毁**——这是新手第一大坑。
4. **续流二极管（flyback diode）**：电磁铁/电机/继电器都是电感，断电瞬间会产生上百伏反向尖峰，能瞬间打穿 MOSFET 和 MCU。必须在负载两端**反并联**一个二极管（1N4007 或肖特基 1N5819），**方向装反 = 直接短路**。
5. **共地（common ground）**：MCU 的 GND 和功率电源的 GND 必须连在一起，否则电平没有参考点，行为完全随机。
6. **上拉/下拉电阻**：MOSFET 栅极要加一个 10kΩ 下拉到地，否则 MCU 复位期间栅极悬空，电磁铁可能自己吸合。栅极串联 100~220Ω 限制开关电流尖峰。
7. **电源余量**：按"最坏情况同时导通"算电流，再乘 1.5。开关电源过载会掉压，掉压会让 MCU 复位。并联一个 1000µF 电解电容吸收电流尖峰。
8. **占空比与发热**：电磁铁是按"短时工作"设计的。持续 100% 通电会到 80°C+。用 **peak-and-hold** 解决（见 Phase 0 代码）。

### 怎么学
- 边看边做：Paul Scherz《Practical Electronics for Inventors》第 2、4 章（电阻/电容/二极管/晶体管），只看这几章。
- 买一个**万用表**（几十块的就行），学会量电压、量通断、量电流。**不会用万用表就等于闭着眼调试。**
- 产出：在纸上画出你的驱动电路，标出每个元件的作用。

## 第 2 组 · 嵌入式 C（贯穿全程）

不需要学"完整的 C 语言"，需要的是这几个概念：

| 概念 | 干什么用 | 在本项目里 |
|---|---|---|
| GPIO 输入/输出 | 开关一个引脚 | 驱动 MOSFET |
| PWM | 用方波"调平均功率" | peak-and-hold 的 hold 阶段、力度控制 |
| 定时器 / 中断 | 精确地"每隔 X 时间做一件事" | 音符时序、软件 PWM |
| 串口 UART | 和电脑通信 | 上位机发音符 |
| 状态机 | 用变量记住"现在在哪一步" | 每个键的 IDLE/PEAK/HOLD 状态 |
| **非阻塞编程** | 用 `millis()` 而不是 `delay()` | **8 个键要同时独立计时，`delay()` 会全卡死** |

**非阻塞是这一组的核心。** 新手写的第一版代码几乎都是 `digitalWrite(HIGH); delay(30); digitalWrite(LOW);`——这在单键时能跑，多键时立刻崩溃。Phase 0 的代码就是按非阻塞状态机写的，照着理解。

学习资源：Arduino 官方 Reference（`millis`、`analogWrite`、`attachInterrupt` 三页）+ 直接读本仓库 `code/` 里的注释。

## 第 3 组 · MIDI 协议（半天到 1 天）

**MIDI 是这个项目的"乐谱数据格式"，整条数据链的输入端。** 不理解 MIDI 就没法做任何自动演奏。

只需要懂 4 个概念：

- **Note number**：音高编号，0~127。中央 C = **60**，每 +1 是半音，每 +12 是一个八度。C4=60, D4=62, E4=64, F4=65, G4=67, A4=69, B4=71, C5=72（这 8 个就是 Phase 1 的 8 个白键）。
- **Note On / Note Off**：按下 / 松开。**注意**：`Note On` 且 velocity=0 等价于 `Note Off`，很多 MIDI 文件这么写，解析时必须处理，否则音符永远不松开（→ 电磁铁常通 → 冒烟）。
- **Velocity**：力度 0~127。你的机器要把它映射成敲击强度。
- **Delta time / tempo**：音符之间的时间间隔。用 `mido` 库的话它会帮你换算成秒。

工具：装 `pip install mido python-rtmidi`，用 MuseScore（免费）看和导出 MIDI 文件。

## 第 5 组 · 机械基础（Phase 2 再学，约 2 周）

- **力与力矩**：舵机标称"kg·cm"是力矩——`10kg·cm` 意思是力臂 1cm 处能提 10kg。手指连杆越长，末端力越小。**Phase 4 选舵机前必须会算这个。**
- **行程与刚度**：琴键下沉约 10mm；框架刚度不够，反作用力会把整个架子顶起来，敲击力就漏掉了。
- **公差与配合**：3D 打印孔要比轴大 0.2~0.4mm 才装得进去（见 `3d-printing.md`）。
- **传动方式**：同步带（快、轻、有回差）、丝杆（准、慢、自锁）、齿轮（改变力矩/速度比）、连杆（把旋转变直线，手指关节常用）。

学习方式：不用啃教材，看几个 3D 打印机/机械臂的开源结构（Voron、AR4 机械臂）就懂七成。

## 第 6 组 · 控制理论入门（Phase 4 再学，约 3 周）

- **开环 vs 闭环**：电磁铁敲键是开环（发完指令不管结果）；带编码器的关节是闭环。
- **PID**：闭环最基础的算法。理解 P（比例，快但会超调）、I（积分，消除稳态误差）、D（微分，抑制振荡）三项，会手工调参即可，暂时不需要传递函数和根轨迹。
- **正/逆运动学**：Phase 4 的核心。Lynch & Park《Modern Robotics》第 4、6 章，配 Coursera 同名课程（有中文字幕）。
- **轨迹规划**：梯形速度曲线、S 曲线——让电机加减速平滑，不然会丢步、震动。
