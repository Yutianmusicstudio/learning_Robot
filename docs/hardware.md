# 硬件选型、BOM 与避坑

---

## 一、先选"琴"：不要一上来碰真钢琴

| | 电子琴 / 电钢琴 | 真钢琴（立式/三角） |
|---|---|---|
| 按键所需力 | 轻，约 0.3~0.8N（合成器键更轻） | 静态约 0.5N，但**要发声必须给足动能**，等效需求高 3~5 倍 |
| 力学模型 | 近似"压下开关" | 复杂击弦机（杠杆放大 + 联动 + 制音器），弹起来是"甩"不是"压" |
| 弄坏的代价 | 二手 200 元 | 几千到几万，调律师上门 |
| 反馈 | 有 MIDI 输出，能自动验证机器人弹对没有 | 只能靠录音分析 |

**结论：Phase 0~4 全程用二手 61 键电子琴。** 而且它带 MIDI OUT，可以把"机器人弹的"回读进电脑，自动比对乐谱——这是极好的调试手段，真钢琴没有。

真钢琴等你 L2 完成、且真的需要时再考虑，届时需要更大推力电磁铁（12V/24V，2A+）和更硬的框架。

## 二、执行器选型：为什么是电磁铁

| 方案 | 响应速度 | 力 | 成本/键 | 结论 |
|---|---|---|---|---|
| **推拉电磁铁 (solenoid)** | **~10ms，最快** | 5~20N | 10~25 元 | ✅ **按键首选** |
| 舵机 SG90/MG996R | 60° 需 100~200ms | 够 | 8~40 元 | 太慢，做不了快速乐句；适合 Phase 4 的关节，不适合直接按键 |
| 继电器 | 5~15ms 且寿命只有 10 万次 | — | — | ❌ 不能用，它是开关不是执行器 |
| 步进电机 | 中等 | 大 | 30 元+ | ✅ 适合 Phase 4 的**横移轴**，不适合按键 |
| 音圈电机 (voice coil) | 极快，可力控 | 中 | 贵 | 专业级方案，L3 用 |

### 电磁铁具体怎么挑
- **类型**：**推式 / 推拉式（push-pull）**，不要吸盘式电磁铁（那个是吸铁的）。
- **参考型号**：`JF-0530B`（12V，行程 5mm，推力约 5N）、`JF-0826B`（力更大）、或搜"推拉式电磁铁 12V 5mm"。
- **电压**：选 **12V** 而不是 5V。同样功率下 12V 电流小、线细好走线、掉压不敏感。
- **行程**：≥5mm（琴键下沉约 10mm，但电磁铁装得近可以只用一部分行程；行程越长响应越慢）。
- **推力**：电子琴 5N 足够；**注意标称推力通常是"吸合末端"的值，行程起点的力要小得多**，所以别卡着最小值选。
- **占空比标注**：注意看是不是标了"25% 占空比"——这类型号绝对不能长通电。

先买 **2 个试打**，验证行程/推力/噪音，再批量买 8 个、25 个。

## 三、驱动电路（本项目最关键的电子部分）

### 单通道电路

```
   Arduino D2 ──[220Ω]──┬── G (栅极)
                        │
                     [10kΩ]        MOSFET  IRLZ44N
                        │
                       GND         D (漏极) ── 电磁铁 (-)
                                   S (源极) ── GND (与 12V 电源共地)

   12V+ ──┬── 电磁铁 (+)
          │
          └──|◀|── 二极管 1N4007，白环(阴极)朝 12V+，反并联在电磁铁两端

   12V 电源正负极之间并联 1000µF/25V 电解电容
```

### 元件清单与理由

| 元件 | 型号 | 为什么是它 |
|---|---|---|
| MOSFET | **IRLZ44N** / IRL540N / AOD4184 | **必须 logic-level**（5V 栅压能完全导通）。⚠️ **不要买 IRF540N**——它要 10V 栅压，5V 驱动会半导通发烫烧毁，是新手第一大坑 |
| 续流二极管 | 1N4007（便宜）或 1N5819 肖特基（更快更好） | 泄放线圈断电反电动势，**不装必烧 MOSFET/MCU** |
| 栅极串阻 | 220Ω | 限制开关瞬间的栅极充电电流，保护 MCU 引脚 |
| 栅极下拉 | 10kΩ 到 GND | MCU 复位/掉电时栅极不悬空，防止电磁铁乱动 |
| 滤波电容 | 1000µF / 25V 电解 | 吸收开关瞬间的电流尖峰，防止电源掉压导致 MCU 复位 |
| 光耦（可选，推荐） | PC817 + 独立驱动电源 | 把 MCU 和功率部分电气隔离，最保险 |

### 想省事的替代方案
- **8 路 MOSFET 驱动模块**（搜"8路 MOS管 驱动模块 高电平触发"）：约 20~40 元，MOSFET + 限流 + 指示灯都焊好了。**Phase 1 强烈建议直接买这个**，把时间花在软件和机械上。注意确认它带续流二极管，不带就自己在负载端补。
- **ULN2803** 达林顿阵列：8 路集成、自带续流二极管，非常方便，但**单路仅 500mA 且压降约 1V（发热）**。小电磁铁可用，大的不行。

## 四、通道扩展（超过 8 键时）

| 方案 | 线数 | 通道数 | 特点 |
|---|---|---|---|
| **74HC595 级联** | 3 (SER/SRCLK/RCLK) | 每片 8 路，可无限级联 | 便宜（几毛钱一片）、简单，**但只有开/关**，要 PWM 得靠软件快速刷新 |
| **PCA9685** | 2 (I2C) | 每块 16 路**硬件 PWM**，可挂 62 块 | 力度控制/舵机的最佳选择，约 10 元一块 |
| 直接用 STM32 引脚 | — | 几十路 | Phase 3 之后，STM32 引脚多，简单粗暴也行 |

**推荐组合**：Phase 2 用 **PCA9685 → MOSFET 阵列**。硬件 PWM 意味着 peak-and-hold 和力度控制都不占 CPU。

## 五、功率预算（一定要算，不算就会烧/掉压）

单个 12V 电磁铁按 0.5A 估算：

| 键数 | 假设最多同时按 | 峰值电流 | 电源建议 |
|---|---|---|---|
| 8 | 8（最坏） | 4A | 12V / 6A（72W） |
| 25 | 10（现实和弦上限） | 5A | 12V / 10A（120W） |
| 25 | 25（绝对最坏） | 12.5A | 12V / 15A，或**在固件里限制同时导通数** |
| 61 | 12 | 6A | 12V / 15A + 分区供电 |

要点：
- **peak-and-hold 让平均电流降到峰值的 1/3 左右**，所以电源可以按"峰值电流 × 1.5，但假设同时导通数 ≤ 12"来选，不必按全键最坏情况。
- 固件里加一个 **"同时导通数上限"** 保护，超了就拒绝或延迟——这比买更大电源便宜。
- 主电源线用 **≥18AWG**（约 0.75mm²），面包板载流只有 1~2A，**大电流不要走面包板**，用接线端子排。

## 七、安全清单（贴在工作台上）

- [ ] 上电前用万用表**量一次电源正负是否短路**。
- [ ] MOSFET 的 G/D/S 别接错（IRLZ44N 正面看引脚从左到右是 **G / D / S**，D 和金属散热片相连）。
- [ ] 二极管方向：**白环（阴极）接电源正极**那一端。
- [ ] MCU GND 与功率 GND **必须连通**。
- [ ] 手边放一个**总开关 / 可断电插排**，异常时第一时间断电。
- [ ] 首次上电用**手放在电磁铁上感受温度**，30 秒内明显烫手就立刻断电查 hold 占空比。
- [ ] 长时间调试时，人不要离开。
- [ ] 12V 低压不电人，但**大电流短路会引燃导线**——不要用细线接主电源。
