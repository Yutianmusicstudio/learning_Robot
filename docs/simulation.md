# 物理仿真：机器人公司为什么用，你什么时候该用

## 一、先回答"我要不要学"

**要学，但不是现在。** 分三句话：

1. **Phase 0~3（电磁铁直上直下按键）：仿真收益接近零。** 电磁铁的运动是一维、开环、无碰撞规划问题。仿真能告诉你的一切，你在真机上 5 分钟就能测出来。这个阶段的"仿真器"就是那台电子琴。
2. **Phase 4（会移动的手指/手臂）：仿真开始真正省钱省时间。** 因为这时你要回答"够不够得着""会不会自撞""轨迹平不平滑""需要多大力矩"——这些问题在造出来之前必须知道答案，改一行代码 vs 重打一套连杆。
3. **Phase 5（学习类算法）：仿真变成必需品。** 强化学习需要几百万次试错，真机做不到。

---

## 二、机器人公司到底用仿真干什么

不是"炫酷可视化"，而是四件很具体的事：

| 用途 | 具体是什么 | 你在 Phase 4 会遇到 |
|---|---|---|
| **运动学验证** | 工作空间够不够、逆解有没有奇异点 | 手指能不能够到 2 个八度外的键 |
| **碰撞检测** | 自碰撞、与环境碰撞 | 两根手指会不会撞在一起、会不会撞到琴体 |
| **动力学 / 选型** | 各关节需要的力矩、电机选多大 | 舵机 kg·cm 够不够 |
| **算法开发（最重要）** | 控制器、轨迹规划、强化学习的试错场 | 指法分配、轨迹时间参数化 |

还有一个隐藏价值：**仿真里摔坏机器人不要钱**。真机调 PID 调错一个参数可能撞坏结构件。

## 三、软件选型对比

| 软件 | 上手难度 | 强项 | 弱点 | 建议 |
|---|---|---|---|---|
| **PyBullet** | ★（最低） | `pip install pybullet` 就能跑；Python 原生；文档少但例子多 | 接触模型精度一般，渲染朴素 | ✅ **第一站**。两周内搞懂 URDF、正逆运动学、碰撞 |
| **MuJoCo** | ★★ | **接触/摩擦力学业界最好**，已被 DeepMind 开源免费；Python API 干净；仿真极快 | 模型格式是 MJCF（和 URDF 有差异） | ✅ **本项目最对口**——"手指压下琴键"正是接触力问题 |
| **Gazebo (+ ROS 2)** | ★★★★ | 工业/学术标准，传感器插件生态完整，能直接跑真机同一套 ROS 代码 | 学习曲线陡；要先学 ROS 2 | 想走机器人行业时学；本项目非必需 |
| **Webots** | ★★ | 开源、自带大量教程和现成机器人模型，对教学友好 | 生态比 Gazebo 小 | 想要"图形化 + 教程完整"可选它替代 PyBullet |
| **CoppeliaSim (V-REP)** | ★★ | 图形化拖拽建模，内置多种物理引擎，教育版免费 | 脚本体系比较独特 | 不喜欢纯代码可以试 |
| **Isaac Sim / Isaac Lab** | ★★★★★ | 高保真渲染 + GPU 并行数千环境，强化学习/sim-to-real 首选 | 需要 NVIDIA 独显（8GB+），装环境麻烦 | Phase 5 再说 |
| **Fusion 360 运动仿真** | ★ | 画完结构顺手就能验证行程和干涉 | 只做机构，不做控制算法 | ✅ **性价比最高**，Phase 2 学 CAD 时顺带就会了 |

### 给你的具体建议

```
Phase 2   Fusion 360 的 Motion Study —— 验证机构行程、干涉。零额外学习成本
Phase 4   PyBullet（2 周入门） → MuJoCo（做接触力和手指按键）
Phase 5   如果走 RL：Isaac Lab；如果走行业：ROS 2 + Gazebo
```

## 四、Phase 4 的仿真学习路径（约 4 周）

### 第 1 周 · 搞懂 URDF
URDF 是描述机器人"有哪些连杆、怎么连、关节怎么转"的 XML 格式，是所有仿真器的通用语言。
- 学 link（连杆）、joint（关节：revolute 旋转 / prismatic 直线 / fixed 固定）、origin（坐标变换）、inertial（质量惯量）、collision vs visual。
- **Fusion 360 有插件可以把装配体直接导出成 URDF**（搜 fusion2urdf），你的 CAD 模型能直接变成仿真模型——这是把 Phase 2 和 Phase 4 打通的关键一步。
- 产出：一个 2 自由度手指的 URDF，在 PyBullet 里能看见、能转关节。

### 第 2 周 · 正/逆运动学
- 正解：给关节角 → 算指尖在哪（就是矩阵连乘）。
- 逆解：给目标位置 → 算关节角（2 自由度可以手推三角函数；多自由度用数值解，PyBullet 自带 `calculateInverseKinematics`）。
- 产出：输入一个琴键编号，仿真里手指指尖落到那个键的正上方。

### 第 3 周 · 轨迹与碰撞
- 关节空间插值 vs 笛卡尔空间插值的区别。
- 梯形/S 曲线速度规划（避免电机丢步和震动）。
- 用仿真检测：手指移动过程中会不会碰到相邻的键或另一根手指。
- 产出：一段"从 C4 移到 G4 并按下"的完整轨迹，在时间上满足乐曲的音符间隔。

### 第 4 周 · 接触力（换 MuJoCo）
- 建一个带弹簧阻尼的"琴键"模型，测手指要施加多大力、多快才能触发。
- 标定：把仿真参数调到和真实电子琴的手感一致（这一步叫 **system identification**，是 sim-to-real 的核心）。
- 产出：仿真里算出的按键力，在真机上验证误差 < 30%。

## 五、必须知道的一件事：Sim-to-Real Gap

仿真里完美的东西，到真机上经常不管用。差异来自：
- 摩擦、间隙（backlash）、皮带弹性——仿真里默认没有
- 电机响应延迟、通信延迟
- 3D 打印件的实际刚度远低于 CAD 里的理想刚体
- 琴键的真实力学（阻尼、回弹）远比模型复杂

对策：
1. **不要追求"仿真完全逼真"**，那是无底洞。用仿真回答**定性问题**（够得着吗？会撞吗？大致要多大力矩？），用真机回答**定量问题**。
2. 做 **domain randomization**：仿真时随机扰动摩擦系数、质量、延迟，让你的控制器对误差鲁棒。这是 sim-to-real 的标准手段。
3. **凡是能在真机上花 10 分钟测出来的，就别花 3 天在仿真里建模。**

---

## 六、一句话总结

> 仿真是"造之前先想清楚"的工具。**你现在还没到"造"的那一步，所以先别学。**
> 等你有了会动的手指、要决定连杆多长舵机多大时，PyBullet 两周入门，MuJoCo 再两周，够用了。
