# 硬件本位路线（STM32 + PCB，自己完成）

> **本文取代 [`roadmap.md`](roadmap.md) 的阶段划分。**
> 原路线是"先用 Arduino 快速出声，Phase 3 再迁移 STM32"，那是按"以音乐成果为目标"排的。
> 你的目标是硬件能力，所以重排：**硬件从一开始就走 STM32，最终形态是自己的 PCB。**

---

## 一、先把两件事分开（这是最关键的判断）

很多人把这两个问题混成一个，然后要么走弯路，要么打废板子：

| 问题 | 答案 |
|---|---|
| **Arduino 能不能跳过？** | **能。** 直接上 STM32，不必先做一遍再迁移 |
| **面包板能不能跳过？** | **绝对不能。** 先画 PCB 后验证电路 = 保证要打第二版 |

**PCB 是"把已经验证过的电路固化下来"，不是"设计电路的地方"。**
你必须先在面包板上把拓扑、功率、发热全部跑通，再去画板。

## 二、软件上的取巧：STM32 硬件 + Arduino 框架起步

直接啃 CubeMX + HAL + 时钟树，很多人两周还没点亮一个灯，然后就放弃了。

**更好的路径：**

```
PlatformIO + STM32duino（Arduino 框架跑在 STM32 上）
   ↓  你熟悉的 API，当天就能点灯
   ↓  逐步下沉——只在需要的地方换成 HAL / 寄存器
硬件定时器 → DMA → USB-MIDI Class
```

硬件从第一天就是 STM32（不浪费），软件的学习曲线被拉平。

## 三、选板

**先去问实验室有没有。** 实验室通常有一抽屉开发板，免费。

自己买的话：

| 板子 | 价格 | 说明 |
|---|---|---|
| **NUCLEO-F446ZE**（推荐） | ~$25~30 | **板载 ST-Link 调试器** + 独立的用户 USB 口（做 USB-MIDI 用）+ 144 脚海量 GPIO。官方板、文档全 |
| WeAct BlackPill F411 | ~$7 + ST-Link 克隆 $4 | 便宜、USB-C 直连 MCU，USB-MIDI 开箱可用。但要另配调试器 |
| ~~STM32F103 Blue Pill~~ | — | **别买**。USB 有坑，且市面山寨芯片泛滥 |

> **板载调试器值回票价。** 没有调试器硬啃 STM32，是新手放弃的第一大原因。
> 价格与供货会变动，下单前自行核对。

## 四、第一块 PCB 该画什么

### 铁律：小、模块化、可级联

**不要一上来画一块 88 通道大板。** 第一块板一定有错——错在小板上损失 $2，错在大板上损失整个项目的士气。

### v1 规格：8 通道 MOSFET 驱动模块

| 项 | 设计 |
|---|---|
| 通道数 | **8**（要 24 路就叠 3 块） |
| 输入 | 8 路逻辑信号（IDC 排线座）+ 12V + GND |
| 每通道 | 栅极串阻 **220Ω** · 栅极下拉 **10kΩ** · **IRLZ44N**（TO-220 通孔）· 续流二极管 **SS34/1N5819** |
| 输出 | **螺钉接线端子**接电磁铁（别用排针，大电流会烧） |
| 板载 | 1000µF 电解 · 电源指示 LED · ★ **每通道一个状态 LED** |
| 封装 | **v1 全部用通孔件** |
| 尺寸 | **控制在 100×100mm 以内** |

**两个设计决定值得解释：**

- **每通道一个 LED**：调试神器。没有示波器也能一眼看出哪一路在动、哪一路没反应。多花 8 个 LED 的钱，省下无数小时。
- **v1 全通孔**：你**一定会烧掉几个 MOSFET**。通孔件好换、好散热、好手焊。板子大一点无所谓。

### 100×100mm 这个数字不是随便定的
JLCPCB 的最便宜档就是 **2 层 / 5 片 / ≤100×100mm**，约 **$2~5 + 运费**。
超一点点，价格就跳档。**把板子设计进这个框里，你就能几乎免费地迭代。**

### 校内铣床 vs JLCPCB：两个都用，不是二选一

若学校有 PCB 铣床（如 LPKF；Georgia Tech 的 **The Hive / IDC** 就有一整套），
它和 JLCPCB 解决的是不同问题：

| | 校内 LPKF 铣床 | JLCPCB |
|---|---|---|
| 拿到板 | **当天，1~2 小时** | 约一周 |
| 阻焊层 / 丝印 | **没有**（裸铜，易氧化、手焊易连锡） | 有 |
| 过孔电镀 | **没有**，双面板过孔要手工穿铆钉 ← 最大痛点 | 有 |
| 成本 | 通常免费 | $2~5 / 5 片 + 运费 |
| 适合 | **快速试错、验证布局** | **最终版、多块级联、要好焊好看** |

**最优流程：**
1. 先在校内铣一块 **v1**，当天焊上验证 → 几小时内发现设计错误，而不是等一周
2. 改完之后把最终版发 **JLCPCB** 打 5 片 → 有阻焊、好焊、可以给别人

> **为铣床设计时，把板子做成单面板**（元件在顶面、走线在底面），
> 就完全绕开了手工过孔的痛苦。功率驱动板线粗、过孔少，很容易做到单面。

### 工具
- **KiCad**（推荐）：免费开源、无厂商绑定、社区大、学校里也普遍在用
- EasyEDA / 立创EDA：上手更快、和 JLCPCB 打通，但绑定较深

流程：画原理图 → 画 PCB → 导出 Gerber → 上传 JLCPCB → 5 片到手（美国约一周）

## 六、"自己完成"的正确理解

**自己完成 = 自己动手，不等于自己重新发明。**

去问实验室那些问题（执行器型号、驱动拓扑、电源实际峰值电流、机架怎么防共振），
抄一个已经验证过的电路拓扑——**这不会让这个项目变得不是你的**。

每一个硬件工程师都是这么做的。真正属于你的是：你焊的板、你调的参数、你解决的那些别人没遇到过的问题。

**不必要的从零开始，不是骨气，是浪费。**
