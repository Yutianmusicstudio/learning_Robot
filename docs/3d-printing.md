# 3D 打印：要学，但学的重点不是打印机

## 一句话结论

**你要学的是 CAD（建模），打印机只是输出设备。** 会建模但没打印机 → 花几块钱找代打印就行；有打印机但不会建模 → 只能下载别人的模型，对本项目毫无用处。

**什么时候开始学：Phase 2**（约第 9 周）。Phase 0/1 用木板和铝型材就够了，提前学会拖慢进度。

---

## 二、在这个项目里，3D 打印到底解决什么问题

| 零件 | 为什么必须打印 |
|---|---|
| **电磁铁夹具** | 25 个电磁铁要精确固定在每个琴键正上方，间距 23.5mm（白键），高度可微调。手工做 25 个一致的支架几乎不可能 |
| **黑键高度补偿件** | 黑键比白键高约 10mm、窄约一半，需要不同的推杆长度和定位 |
| **推杆头（软触头）** | 电磁铁铁芯直接砸琴键会有噪音和磨损，需要一个带缓冲的接触头（可打印 TPU） |
| **横梁滑块** | 让每个模块能沿铝型材滑动定位、锁紧 |
| **Phase 4 的手指连杆、齿轮、外壳** | 定制机构，只能自己做 |

关键词是 **"同一个零件要精确重复 25 次"** ——这正是 3D 打印相对手工的绝对优势。

## 三、学 CAD：选哪个软件

| 软件 | 价格 | 推荐度 | 说明 |
|---|---|---|---|
| **Fusion 360** | 个人版免费 | ★★★★★ | **机械设计首选**。参数化建模（改一个尺寸，整个模型跟着变）、装配体、自带运动仿真和应力分析。教程极多 |
| **Onshape** | 免费（公开文档） | ★★★★ | 纯网页，不挑电脑，协作好。免费版模型是公开的 |
| **SolidWorks** | 学生版/教育版 | ★★★★ | 工业标准，如果学校有授权就用它，思路和 Fusion 相通 |
| **FreeCAD** | 开源免费 | ★★★ | 完全免费无限制，但操作逻辑绕，新手容易劝退 |
| **Tinkercad** | 免费 | ★★ | 太简单，做不了本项目需要的精确装配 |
| Blender | 免费 | ✗ | 是艺术建模，**不适合做机械件** |

**建议：Fusion 360。** 学习路径（约 2 周，每天 1 小时）：
1. 草图（Sketch）+ 约束 + 拉伸（Extrude）—— 能画出带孔的板子
2. **参数（Parameters）** —— 把"琴键间距""电磁铁直径"设成变量，改一个数全套零件更新。**这是本项目最重要的功能**
3. 装配体（Assembly）+ 关节（Joint）—— 把电磁铁模型和夹具装配起来，检查干涉
4. 导出 STL / 3MF

## 四、打印机：买还是不买

### 先不买的方案（推荐先走这条）
- **代打印**：淘宝、嘉立创 3D、打印工厂。一个小夹具几块到十几块，PLA 常规件很便宜。
- 打样 2~3 个验证公差，确认后再决定要不要买机器。
- 缺点：一次迭代要等 3~7 天。**如果你确定要做到 Phase 4，买机器是划算的**——机械设计的本质是快速迭代。

### 要买的话
| 机型 | 价格(¥) | 说明 |
|---|---|---|
| **Bambu Lab A1 mini** | ~1500 | 开箱即用、自动调平、故障率低。**新手最省心**，尺寸 180³ 够本项目大部分零件 |
| **Bambu Lab A1 / P1S** | 2500~4500 | 更大尺寸，P1S 带箱体可打 ABS/ASA |
| Prusa MK4 | ~6000 | 开源、可靠、社区强 |
| Creality Ender-3 系列 | ~800 | 便宜，但需要自己调试折腾。**你想学的是机器人不是修打印机，不建议** |

**给你的建议：先代打印验证 2 次，确定项目能推进到 Phase 2 之后，再买 A1 mini。**

## 五、材料怎么选

| 材料 | 强度 | 耐温 | 难度 | 本项目用途 |
|---|---|---|---|---|
| **PLA** | 中 | 差（~55°C 就软） | 最易打 | 快速原型、外观件。**不要用在电磁铁旁边**（电磁铁工作温度能到 60~80°C，会把 PLA 烤软变形） |
| **PETG** | 好，有韧性 | ~75°C | 简单 | ✅ **本项目结构件首选**：夹具、支架 |
| **ABS / ASA** | 好 | ~95°C | 需要箱体，会翘边 | 靠近电磁铁的高温件 |
| **尼龙 PA / PA-CF** | 很好 | 高 | 难，要烘干 | Phase 4 的齿轮、耐磨件 |
| **TPU（软胶）** | 弹性 | — | 中等 | ✅ 推杆头缓冲垫、减震 |

**记住这条：PLA 打原型，PETG 打正式件，电磁铁附近别用 PLA。**

## 六、机械设计的 8 条实用规范（新手必踩的坑）

1. **公差**：打印孔会缩小。要装 M3 螺丝的过孔画 **3.2~3.4mm**；要压入的轴孔比轴大 **0.1~0.2mm**。第一次打一个"公差测试块"（一排 3.0/3.2/3.4/3.6mm 的孔）省下无数次返工。
2. **各向异性**：打印件**层与层之间最弱**。受拉/受弯的方向要顺着层面，不能垂直于层面。薄的悬臂平躺打印比立着打强好几倍。
3. **45° 悬垂规则**：超过 45° 的悬空面需要支撑，支撑面会很丑很粗糙。**设计时就把配合面朝下或朝上，避免落在支撑上**。
4. **不要打印螺纹**：用**热熔铜螺母**（M3 黄铜嵌件，烙铁一压就进去），比打印螺纹牢固十倍。这是 3D 打印机械件的标准做法。
5. **加圆角（fillet）**：内直角是应力集中点，是零件断裂的起点。所有内角加 1~2mm 圆角。
6. **壁厚 ≥ 3 层**（约 1.2mm），受力件填充率 **30~50%**，不要用 100%（慢、翘、还不见得更强）。
7. **能拆成小件就拆**：一个大零件打 8 小时打废了就全废；拆成 4 个小件，坏一个补一个。用螺栓连接。
8. **先打一个"接口测试件"**：只打夹具上跟电磁铁配合的那一小段，验证紧不紧，再打完整件。**永远不要第一次就打全套 25 个。**

## 七、切片软件

切片 = 把 3D 模型切成一层层的打印机指令。

- **Bambu Studio**（拓竹机器）/ **OrcaSlicer**（通用，功能最全，推荐）/ **PrusaSlicer** / **Cura**
- 新手只需要动这 5 个参数：层高（0.2mm 通用）、填充率、壁厚（walls，设 3~4）、支撑（开/关）、材料预设。其余全用默认。

## 八、除了 3D 打印的替代/补充方案

不要以为所有东西都得打印，**混合使用效率最高**：

| 方式 | 适合 |
|---|---|
| **2020 铝型材** + 角件 | 主框架。刚性远超打印件，便宜，可随意调整。**Phase 1/2 的横梁一定用这个** |
| **激光切割亚克力/木板** | 平板件，比打印快得多也便宜，淘宝按面积算钱 |
| **标准件**（螺栓、直线导轨、轴承、GT2 同步带轮） | **能买到的绝不自己打印**。打印件用来做"把标准件连起来的接口" |
| **手工木工** | Phase 0/1 的临时支架，两块木板加螺丝一小时搞定 |

**核心心法：3D 打印负责"定制的连接接口"，标准件负责"承力和精度"。**

## 九、学习路径（2 周）

```
第 1~3 天   Fusion 360 界面 + 草图 + 拉伸        → 画出一块带 4 个 M3 孔的板
第 4~5 天   参数化（Parameters）                 → 把琴键间距设成变量
第 6~7 天   装配体 + 干涉检查                     → 电磁铁 + 夹具装在一起
第 8~9 天   导出 STL + 切片 + 送代打印            → 收到第一个实物
第 10~14 天 按实测公差修模型，打第二版             → 装得上、锁得紧
```

教程推荐：B 站搜"Fusion 360 入门 参数化"；官方 Autodesk Fusion 360 学习中心；YouTube 频道 "Product Design Online" 的 30 天挑战。
