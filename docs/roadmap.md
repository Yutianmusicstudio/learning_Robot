# 六阶段详细路线图

每个阶段都有明确的**验收标准**。做不到就别进下一阶段——机器人项目最常见的失败是"基础没稳就加复杂度"。

---

## Phase 0 · 安全与基本功（约 2 周）

**目标：让一个电磁铁，按你的指令，敲响电子琴上的一个键。**

### 要做的事
1. 学完 [`prerequisites.md`](prerequisites.md) 的"第 1 组：电子安全常识"（约 3 小时，但要动手量）。
2. Arduino 点灯 → PWM 调亮度 → `millis()` 非阻塞定时（**不要用 `delay()`**，后面多键并发时 `delay()` 会毁掉一切）。
3. 搭第一个功率电路：Arduino 引脚 → 220Ω → MOSFET 栅极；MOSFET 漏极 → 电磁铁 → 12V；电磁铁两端**反并联一个 1N4007**（带白环的负极接 12V 正）。Arduino GND 与 12V 电源 GND **必须连一起**。
4. 烧录 [`code/phase0_single_solenoid`](../code/phase0_single_solenoid)，理解里面的 peak-and-hold。
5. 用手机慢动作拍摄敲击过程，观察行程够不够、回弹快不快。

### 验收标准
- [ ] 电磁铁能稳定敲响琴键，连续敲 100 次不丢音。
- [ ] 连续工作 5 分钟后，电磁铁外壳**用手能一直摸住**（说明 hold 占空比正确）。
- [ ] 你能画出这个电路图并解释：为什么要续流二极管、为什么要共地、为什么栅极要串电阻。

### 常见卡点
- 敲不响 → 行程不够（电磁铁离键太远）或推力不足（换 12V 更大推力型号，或加长推杆增大冲击）。
- 一通电 Arduino 就重启 → 电源功率不够或没加大电容；也可能是共地线太细。
- 电磁铁很快烫手 → peak-and-hold 没生效，检查 hold 占空比。

## Phase 1 · 八键自动演奏（约 4 周）

**目标：电脑打开一个 MIDI 文件，机器把它弹出来（8 个白键，C4~C5）。**

### 要做的事
1. 把 Phase 0 的电路复制 8 份（或直接买一块 8 路 MOSFET 驱动模块，省一半时间）。
2. 用木板/铝型材搭一个粗糙但**刚性足够**的横梁，把 8 个电磁铁架在 C4~C5 八个白键上方。刚性不够 = 反作用力把架子顶起来 = 敲不实。
3. 烧录 [`code/phase1_eight_keys`](../code/phase1_eight_keys)（含 8 路软件 PWM + 串口协议）。
4. 跑 [`code/host/play_midi.py`](../code/host/play_midi.py)：Python 用 `mido` 解析 MIDI，按时间戳往串口发音符。
5. 找一个只用白键的 MIDI（《小星星》《欢乐颂》），调试到能听出旋律。

### 验收标准
- [ ] 能完整弹出一首 30 秒的单声部曲子。
- [ ] 能同时按下 3 个键弹和弦，且电源不掉压、Arduino 不重启。
- [ ] 你能解释 MIDI 的 note number、note-on/note-off、velocity 分别是什么。

### 这一阶段真正学到的
时序控制、并发状态机、上位机/下位机通信协议设计、功率预算。**这三样是后面所有阶段的地基。**

## Phase 2 · 机械结构 + 音域扩展（约 6 周）

**目标：25 键（2 个八度，含黑键），结构可靠可拆装，能控制力度。**

### 要做的事
1. **学 CAD**（Fusion 360，见 [`3d-printing.md`](3d-printing.md)），设计：
   - 单个电磁铁的模块化夹具（能沿横梁滑动、锁紧、微调高度）
   - 黑键的高度补偿件（黑键比白键高约 10mm 且更窄）
2. 打印 25 个夹具（或先打 3 个验证公差，再批量）。
3. **通道扩展**：8 个 MCU 引脚不够用了。方案：
   - **74HC595 移位寄存器级联**（3 根线 → 无限多路开关）+ ULN2803/MOSFET 阵列 — 便宜、够用
   - 或 **PCA9685**（I2C，16 路硬件 PWM）— 想做力度控制时更方便，可级联到 62 块
4. **力度控制**：通过改变 peak 阶段的 PWM 占空比 / 持续时间，来改变敲击速度 → 对应 MIDI velocity。做一条 `velocity(0~127) → peak 参数` 的标定曲线（用手机录音测响度，或直接凭听感分 5 档起步）。
5. 电源重新核算：25 键最坏情况同时导通，必须按峰值电流选电源（见 [`hardware.md`](hardware.md) 的功率预算表）。

### 验收标准
- [ ] 能弹一首含黑键、有和弦的两个八度曲子。
- [ ] 强奏/弱奏听得出明显区别。
- [ ] 拆装一个电磁铁模块 < 2 分钟，且不需要重新标定其他键。

## Phase 3 · 迁移到 STM32（约 4 周）

**目标：把固件搬到 STM32，获得 Arduino 给不了的东西。**

### 为什么要搬
| 能力 | Arduino UNO | STM32 |
|---|---|---|
| 定时精度 | 软件 PWM，抖动 ms 级 | 硬件定时器，µs 级 |
| 硬件 PWM 通道 | 6 | 十几~几十 |
| USB 设备 | 需要额外芯片 | **原生可做 USB-MIDI 设备**（电脑直接识别成一台 MIDI 乐器，DAW 里可以直接选它） |
| 内存/算力 | 2KB RAM / 16MHz | 20~256KB / 72~480MHz |

USB-MIDI 这一条是杀手锏：做成 MIDI 设备后，任何音乐软件（Ableton、MuseScore、GarageBand）都能直接驱动你的机器人，不用再写上位机脚本。

### 要做的事
1. 学 STM32 工具链：**STM32CubeMX（图形化配置）+ HAL 库 + CubeIDE**（或 PlatformIO）。国内教程：正点原子 / 野火的 STM32 系列，跟着走 GPIO → 定时器 → PWM → 中断 → USART → USB 这条线即可，其他章节先跳过。
2. 用**硬件定时器 + 中断**重写 peak-and-hold 状态机（每 100µs 一次 tick，比 Arduino 的 loop 轮询稳得多）。
3. 用 CubeMX 的 **USB Device → Audio/MIDI Class**，做成免驱 MIDI 设备。
4. 加一个"急停"：看门狗 + 上电全通道拉低 + 一个物理断电开关。**电磁铁卡在常通状态会冒烟，这个保护必须有。**

### 验收标准
- [ ] 插上 USB，电脑（Windows/macOS）自动识别出一台 MIDI 设备。
- [ ] MuseScore 里播放乐谱，机器人跟着弹，延迟 < 10ms。
- [ ] 拔掉数据线 / 复位 MCU，所有电磁铁立刻断电。

## Phase 4 · 会动的手指（8 周起，L2 开始）

**目标：不再是"一键一执行器"，而是少量能移动的手指覆盖大音域。**

这一阶段开始，你才真正在做"机器人"，也才真正需要运动学和仿真。

### 要做的事
1. **机构选型**：
   - 横移轴：**步进电机 + GT2 同步带 + 直线导轨**（3D 打印机同款方案，便宜成熟）
   - 手指关节：**数字舵机**（如 MG996R / 更好的总线舵机）或小型减速电机 + 编码器
   - 按键动作仍可保留电磁铁（速度快），移动交给步进
2. **学运动学**：正运动学（关节角 → 指尖位置）、逆运动学（我要指尖到那个键 → 各关节转多少）。教材：Lynch & Park《Modern Robotics》（官网有免费 PDF + Coursera 课）。
3. **仿真登场**（见 [`simulation.md`](simulation.md)）：
   - 用 PyBullet 或 MuJoCo 搭一个 URDF 模型，验证：够不够得着最远的键？手指之间会不会撞？轨迹平不平滑？
   - 这时候仿真是真省钱的：改一行代码 vs 重新打印一套连杆。
4. **轨迹规划**：从"当前键"到"下一个键"的移动要在音符间隙内完成 → 这是一个带时间约束的规划问题，也是这个项目最有意思的部分（**指法分配**：哪根手指弹哪个音，本质是个组合优化问题）。
5. **闭环**：加限位开关做回零，加编码器做位置闭环，写你的第一个 PID。

### 验收标准
- [ ] 一根手指能在 200ms 内准确移动到 1 个八度外的任意键并按响。
- [ ] 仿真里跑通的轨迹，在实物上误差 < 3mm。

## Phase 5 · 感知与智能（长期）

方向，不是任务清单：

- **视觉读谱（OMR）**：摄像头拍乐谱 → 音符序列。开源可用 Audiveris；深度学习方向搜 "Optical Music Recognition"。
- **视觉标定**：用摄像头 + ArUco 标记自动找到琴键位置，免去手工标定。OpenCV 就够。
- **力控触键**：FSR 力敏电阻或应变片测触键力，做力闭环 → 真正的强弱表现力和"触后"控制。
- **强化学习**：在 Isaac Lab / MuJoCo 里训练指法策略，再迁移到实物（sim-to-real）。这是当前学术前沿，需要显卡。
- **踏板**：延音踏板一个大电磁铁就能做，性价比极高，音乐表现力提升巨大。**其实这个可以在 Phase 2 就顺手加上。**

## 时间与预算总览

| 阶段 | 时间 | 累计花费（人民币，估） |
|---|---|---|
| Phase 0 | 2 周 | ~400（含二手电子琴 ~200） |
| Phase 1 | 4 周 | ~600 |
| Phase 2 | 6 周 | ~2500（如买 3D 打印机 +1500~3000） |
| Phase 3 | 4 周 | ~2700（STM32 板你已有） |
| Phase 4 | 8 周+ | ~5000+ |

**按每周 8~10 小时投入估算。** Phase 0~3 做完（约半年），你已经有一台能接 MIDI、能弹和弦、有强弱的钢琴机器人，并且掌握了嵌入式 + 机械 + 上位机全栈——这已经超过大部分"学过机器人"的人。
