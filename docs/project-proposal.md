## 0. 一句话

用 STM32 + 自制功率驱动 PCB，做一台 24 键、可被任何音乐软件驱动的钢琴演奏机器人；
六个月内完成，核心自费约 $650~800；并为后续的触键力学研究预留接口。

## 2. 技术清单

### 2.1 硬件层
- 功率电子：MOSFET 开关拓扑、栅极驱动与限流、续流回路、功率预算、热设计
- **peak-and-hold 电流成形**（本项目的核心技巧）
- 电源设计：峰值电流估算、去耦、共地、载流线宽
- **PCB 设计**：KiCad；单面板（为铣床）与 2 层板（为 JLCPCB）；100×100mm 成本档位

### 2.2 固件层
- STM32F446 · PlatformIO + STM32duino **起步**，逐步下沉到 HAL
- 硬件定时器 PWM；**输入捕获**（后续测击弦速度）
- 中断、DMA
- **USB Device MIDI Class**（免驱，被 DAW 直接识别为乐器）
- 非阻塞状态机、实时时序、并发上限保护、看门狗急停
- SimpleFOC / FOC 电流环、阻抗控制（阶段 E）

### 2.3 机械层
- Fusion 360 参数化建模（琴键间距作为变量驱动整套零件）
- 3D 打印设计规范：公差（孔放大 0.2~0.4mm）、层间各向异性、热熔铜螺母、45° 悬垂
- 材料：结构件 PETG（**电磁铁附近不用 PLA**，会被烤软）；缓冲头 TPU
- 2020 铝型材框架与刚度校核

### 2.4 上位机层
- Python：`mido`（MIDI 解析）、`pyserial`
- MIDI 协议：note number / on-off / velocity / tempo
- 数据采集与可视化：numpy、matplotlib
- （研究阶段）音频分析：scipy、librosa

### 2.5 方法论层（阶段 F）
- 对照实验设计、条件随机化、参考基线插值
- ABX 双盲听音测试、逐被试报告
- 混合效应模型；预注册

## 3. 可行性报告

### 3.1 技术可行性：**高**

- **原理无风险。** 电磁铁驱动钢琴演奏是 1987 年就商业化的技术（Yamaha Disklavier，
  现役机型可重放 1024 级琴键/槌头速度、256 级连续踏板）。不存在原理性不确定。
- **本地已有先例。** 所在实验室已有运行中的机器人吉他（按弦阵列 + 旋转拨片轮）
  与机器人打击乐（导轨 + 槌击模块），关键技术——多通道功率驱动、MIDI 架构、
  铝型材机架、3D 打印夹具——在同一空间内已有可参考实现。
- **剩余技术风险集中且有成熟对策**：热管理（peak-and-hold）、机架刚度、多通道时序。

### 3.2 资源可行性：**高**

GT 的 The Hive 与 FIS 覆盖了全部制造与测量需求，且对全校学生免费、不限专业。
核心阶段自费 $650~800、六个月。

**唯一的资源型风险是培训与排队的前置时间**——对策是第 1 周就去办。

### 3.3 能力可行性：**中高**

- **起点**：有编程基础，零电子与机械基础。
- **最大风险是 STM32 的学习曲线**（CubeMX + HAL + 时钟树容易吃掉两周）。
  对策：PlatformIO + STM32duino 起步，当天点灯，只在需要处下沉。
- 采购前置期 2~3 周会打断节奏。对策：批量提前下单、易损件多订一份。

### 3.4 独特性论证：为什么这不是重复劳动

**实验室的乐器谱系存在一个明确缺口：**

| 类别 | 状态 |
|---|---|
| 拨奏弦鸣乐器（吉他） | ✅ 已有 |
| 击奏体鸣乐器（马林巴 / 钟琴） | ✅ 已有 |
| **键盘 / 带击弦机的击奏弦鸣乐器（钢琴）** | ❌ **空缺** |

而钢琴在机构学上是三者中最难的一类：

| | 执行器与发声体的关系 |
|---|---|
| 吉他 | 直接接触琴弦（按 + 拨） |
| 马林巴 | 直接敲击音条 |
| **钢琴** | **完全不接触**。执行器推的是杠杆机构的输入端，中间隔着整套击弦机；
且因**擒纵机构**，撞弦前不到 1ms 琴槌已脱离传动、自由飞行 |

这引入了前两者都不存在的问题：**只能通过一个非线性、带擒纵、会柔性变形的传动机构，
去间接地精确控制发声。** 它对应机器人学中的一般问题——**经由欠驱动 / 柔性传动的间接精确控制**。

### 3.5 风险登记表

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| **范围膨胀** | 高 | 高 | 24 键为硬性核心目标；力控与研究平台明确标为可选 |
| **采购前置期打断节奏** | 高 | 中 | 批量提前下单；易损件永远多订一份 |
| **第一块 PCB 有错** | 高 | 低 | 先在 The Hive 铣一块当天验证；板子压在 100×100mm 内使重打近乎免费 |
| STM32 学习曲线卡住 | 中 | 高 | STM32duino 起步；有板载 ST-Link 可调试 |
| 电磁铁过热 | 中 | 高 | peak-and-hold；首次上电手测温度；示波器验证电流波形 |
| 假 MOSFET 烧毁 MCU | 中 | 中 | 关键半导体只从 DigiKey/Mouser 采购 |
| 机架刚度不足，冲击被吃掉 | 中 | 中 | 2020 铝型材；千分表实测 20N 下挠度 |
| 电源掉压导致 MCU 复位 | 中 | 中 | 按峰值×1.5 选电源 + 1000µF；固件限制同时导通数 |
| makerspace 培训/排队延误 | 中 | 低 | **第 1 周办培训** |
| 找不到免费声学钢琴 | 低 | 中 | 美国供给充足；退路是延后阶段 F |

### 3.6 判定

| 目标 | 可行性 |
|---|---|
| 核心：24 键 USB-MIDI 钢琴机器人 + 自制 PCB | **高** |
| 延伸：BLDC 力控关节 | 中高 |
| 可选：触键力学研究平台 | 中（取决于能否获得声学钢琴与被试） |

## 4. 成果预估

### 4.1 里程碑与量化验收

| 周 | 里程碑 | 量化验收标准 |
|---|---|---|
| 3 | 单键敲响 | 连敲 100 次不丢音；连续 5 分钟后电磁铁外壳可手持 |
| 8 | 8 键演奏 | 完整弹出 30 秒单声部曲子；3 键和弦不掉压、不复位 |
| **12** | **自制 PCB 验证** | 8 通道全部通过；与面包板版行为一致 |
| 16 | 24 键 | 含黑键与和弦的两个八度；强奏/弱奏可听辨 |
| 20 | USB-MIDI 设备 | 电脑免驱识别；MuseScore 播放延迟 < 10ms |
| 24 | 力控关节 | 力跟踪误差 < 5%；可稳定模拟三组不同 (m, k, c) |

### 4.2 分置信度的成果预估

**几乎确定（>90%）· 6 个月**
- 一台 24 键、USB-MIDI 驱动的钢琴演奏机器人
- **一块自己设计、打样、焊接、验证的 8 通道功率驱动 PCB**（3 块级联）
- 四块硬件能力：功率驱动 / 实时嵌入式 / PCB 设计 / 机械与 3D 打印
- 完整开源仓库：固件、上位机、CAD、原理图、BOM、文档

**很可能（~70%）· 9 个月**
- BLDC + FOC 力控单关节，可编程模拟质量 / 刚度 / 阻尼
- 力度控制：velocity → 击打参数的标定曲线
- 可作为课程项目或独立研究学分的成果

**有机会（~40%）· 12 个月+**
- 触键力学测量平台，击弦速度测量重复性 ≤ 1%
- 一份公开数据集（指令 / 指力 / 琴键位移 / 击弦速度 / 音频对齐）
- NIME 或 ISMA 级别的投稿

**低概率但值得标注（<20%）**
- 期刊论文（JASA / Frontiers）
- 转为实验室正式课题

### 4.3 明确的非目标

写下来是为了防止范围膨胀：

- ❌ 88 键全音域
- ❌ 双手仿人机械手（那是 L3，研究所级别）
- ❌ 计算机视觉识谱（数据已存在于 MusicXML，且与触键平台耦合度为零）
- ❌ 商业产品化（且 FIS 明确规定其打印件不得用于出售的产品）
