# 四手联弹协奏机器人：计划与工具（评估版 v2）

作者：Yutian Wang　　日期：2026-09-05　　配套文档：`paper/proposal.tex`
v2 修订：吸收外部评审（`pianobot_feasibility_review.md`）的核查结果。修改处以 † 标出。

---

## 1. 一句话

造一台外置的、按键式的机器人，在 88 键配重 MIDI 数字钢琴上演奏四手联弹写定的 secondo 声部，人在同一键盘上演奏 primo；以合奏时序精度评价。本阶段只做 MIDI 驱动的合奏平台；视觉预判、rubato、自主学习、EEG 为后续阶段。

## 2. 定位

- **出发点**：Wang, Zhang & Iida (IEEE T-RO 40, 2024) 用 UR5 机械臂 + 拟人手为人的旋律即兴弹和弦伴奏。其自述的两条硬件限制——和弦词汇缩至七个三和弦、机械臂横向移动占用按键时间——都与单条运动臂有关。† 和弦词汇限制还涉及任务定义与手部结构，不把"单臂"当作完整因果。
- **本项目的结构选择**：每键一个执行器的固定电磁铁阵列。没有横向行程，因此没有运动规划问题、没有转移时间约束、人手边没有运动结构。代价是表现力受限，需实测（Logos 的标定资料表明电磁铁阵列的表现力不宜先验判死）†。
- **先例边界**：机器与人共用键盘（Risset 1989；Disklavier 系统）、外置逐键 Vorsetzer（Logos Player Piano†；TeoTronico）、外置机器人跟随真人（WABOT-2, 1984）各自都有先例；四者同时成立——外置按键 + 同一键盘 + 写定四手联弹 + 实时跟随——未检索到。这是定向检索而非系统综述，未检索到不等于不存在†。本阶段**不主张任何部件为新**，只主张这一配置及其测量。

## 3. 本阶段的边界条件 †

在动手前先定下来，否则后面的每一步都在流沙上：

| 条件 | 本阶段的选择 | 原因 |
|---|---|---|
| 琴型 | 指定型号的 88 键配重 MIDI 数字钢琴 | 原声钢琴无原生 MIDI 输出；配重键可验证接口与控制，但不代表原声琴的擒纵与发声，原声适配另行验证 |
| 音域 | 人机音域固定、不重叠 | 同键冲突无解：机器人压着的键人无法重击；事件归属靠音高区分，不靠减去指令日志 |
| 曲目 | 先选少量目标曲目，统计音域、最大同时按键数、最快重复音、最短释放间隔、踏板需求 | "44 键覆盖 secondo"是假设，要用曲目数据决定阵列范围 |
| 踏板 | 提前定归属（人或机器人按谱控制） | 同一台琴的延音踏板影响双方声音，不是一个普通执行通道 |
| 领奏 | 本阶段固定真人领奏 | 双向时间协商属 P7 |

## 4. 分阶段计划

时间按一人、课业之外推进估算。

| 阶段 | 内容 | 难度 | 可行性 | 估时 | 主要风险 |
|---|---|---|---|---|---|
| **P0** | 相邻一白一黑两键，Arduino；逻辑在面包板、功率回路走额定导线与端子†；搭好三时间戳测量链路（驱动、键事件、声音）† | 低 | 几乎确定 | 2–4 周 | 测量装置本身；电磁铁撞击声早于乐音音头† |
| **P1** | 8–12 键模块，peak-and-hold 驱动，第一块 PCB。测：冷/热机延迟分布、并发压降、松键复位时间、重复音成功率、几档基本力度的可重复性、长按温升、断电后释放状态† | 低–中 | 高 | 1–2 月 | 保持电流比例需按实际执行器定，30–40% 只是起点†；续流设计可能延缓释放† |
| **P2** | 纯软件合奏：乐谱跟随 + 音高分区归属 + **预测调度**（触发时刻 = 预测发声时刻 − 执行延迟）† + 经数字钢琴音源回放；模拟延迟、抖动、漏音、错音、休止后重入 | 中（集成） | 高 | 1–2 月，与 P1 并行 | 跟随器对复调、反复、错漏音的鲁棒性；启动与失跟恢复策略 |
| **P2.5** † | 用 P1 模块与真人合奏短片段，检验事件归属与跟随闭环 | 中 | 高 | 2–4 周 | 在扩大执行器采购前发现集成问题 |
| **P3** | 按曲目分析结果扩展音域 + 踏板，分段机架，安装验证 | 中 | 高，工作量大 | 2–3 月 | 尺寸链；不伤琴的固定；真人手部活动空间 |
| **P4** | 与人完整合奏曲目；对照实验 | 中 | 高 | 1–2 月 | 抖动与错误预测比固定延迟难补偿 |
| **P5** | 完整逐键力度标定 | 中 | 高 | 约 1 月 | 电磁铁力度可控范围有限 |
| **P6** | 视觉预判 | 高 | 中 | 6–12 月 | 见 §6 |
| **P7** | Rubato：双向时间适应与角色切换 | 高 | 中–低 | 6–12 月 | 见 §6 |
| **P8** | 自主学习 / 即兴 | 高 | 中 | 6–12 月 | 实时 + 实体执行 + 音乐性评估 |
| **P9** | EEG | 见 §7 | 见 §7 | — | — |

**工期** †：限定琴型、曲目、音域且有实验室支持时，P0–P4 合计 6–9 个月是乐观目标；含首次机械与 PCB 开发、约 44 键扩展和可用于论文的人体实验时，按 **9–15 个月**安排。以上未按每周可投入时间与采购周期核算，不作承诺。

**P4 评估口径** †：对照条件——固定速度回放、纯软件预测跟随、实体机器人预测跟随、人—人基线。报告：乐谱同步点上的有符号偏差、绝对误差、离散度与尾部误差；错音、漏音、重复音失败率；速度变化或停顿后的恢复时间；跨速度、曲目、演奏者的表现。"与人—人无显著差异"不等于等效，若要声称接近人—人水平，需事先定义可接受差异。网络二重奏文献中的 10/20/40 ms 是**传输延迟**，不直接等于执行器延迟，不作为通用合格线†。

## 5. 关键设计约束

1. **不打印琴键作为测试对象。** 打印的是支架与触键结构；被触的键用真键。配重数字键与原声键不等效†。
2. **黑键在第一个原型就处理。** P0 即做一白一黑两键。
3. **分段模块化机架。** 每 8–12 键一个模块，各自对齐到键盘。
4. **先验证电路再画 PCB。** 按模块画板，不画 88 通道大板。参考 TI 应用笔记 SLVAE59A 的 peak-and-hold 与快速退磁讨论†。
5. **视觉的价值是提前量，不是更低延迟。**
6. **力度与时序不能完全拆开**†：驱动强度可能改变发声延迟，基础力度可重复性在 P1 就测；完整表现力标定后置到 P5。

## 6. 后续阶段的研究问题（修订后）†

- **P6 视觉**：MuEns 已结合声音与动作信息预测演奏时机，"视觉用于合奏预判"这个想法不新。可成立的问题是：*在写定声部与共享键盘条件下，因果可用的手部视觉信息相对纯 MIDI/乐谱预测，能提供多少有效提前量，并在多大程度上降低实体合奏误差？* 对照纯 MIDI 与 MIDI+视觉，跨演奏者、跨曲目；预测时不得使用目标音头之后的帧。相机帧率是采样粒度问题，"30 fps 不够、120 fps 够"需任务相关证据。
- **P7 Rubato**：Weinberg 等 2009 已有按音量与音符密度切换领奏/跟随的机器人合奏。可成立的问题是写定四手联弹中的*连续*双向时间适应，而非"是否能切换角色"。

## 7. 关于 EEG †

- **人—人条件**：脑间同步（Zamm 等 2021 范式）可用。
- **人—机条件只有一个生物脑**，脑间同步不成立；可用指标是人的 EEG 与其自身行为/声音、与机器人输出之间的耦合。需重新定义问题与对照。
- **作为控制通道**（从脑电预测意图以提前触发）：不进入当前平台的关键路径；本文未做该领域系统综述，不作定量可行性结论。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 反应式触发必然滞后 | P2 起用预测调度；分别测执行延迟、抖动、最终同步误差 |
| 事件归属歧义 / 同键物理冲突 | 音域不重叠；音高分区归属；不依赖指令减法 |
| 电磁铁机械噪声 | 缓冲材料；行程末端 PWM 斜坡 |
| 多路长按发热、并发压降 | peak-and-hold；P1 实测温升与压降 |
| 续流延缓释放、重复音失败 | P1 测复位时间；按 TI 笔记考虑快速退磁 |
| 尺寸链累积 | 分段模块化 |
| 损伤乐器 | 自重与夹持固定，不打孔不粘接 |
| 人手安全与活动空间 | 物理防护；用机架实物验证手部空间 |

## 10. 需要的实验室支持

- 高精度 3D 打印；PCB 加工（12 通道级模块板，多块）
- 一台 88 键配重 MIDI 数字钢琴（型号在 P0 前定）
- 示波器；后期高帧率相机
- 电磁铁、逻辑级 MOSFET、电源等耗材

## 12. 仍待交叉验证的问题 †

1. Wang 等人的和弦词汇限制中，手部机构、运动臂、数据、任务定义各占多少？
2. Logos 及其他 Vorsetzer 项目中是否有更接近本配置的公开记录？
3. 指定键盘的 MIDI 输出能否可靠区分人机事件？非重叠音域是否满足选定曲目？
4. 执行器在目标琴键上的力度—延迟—重复音关系是否支持目标速度？
5. 现有跟随器对复调、反复、错漏音、休止后重入的支持程度？
6. 视觉增益如何证明，避免把"检测到音头"误称为"预测到音头"？
7. 平台与测量本身能形成何种可推广贡献？
